# Quiz Twitch

Application de quiz interactif pour Twitch avec overlay OBS.

## Fonctionnalités

- Les viewers répondent dans le chat Twitch (A, B, C ou D)
- Les points sont comptés automatiquement
- Classement affiché en direct
- Affichage visuel et animé dans OBS
- Création de vos propres questions

## Installation

1. Télécharge le fichier `.exe` dans la section **Releases**
2. Lance l'application
3. Ouvre le panneau de contrôle dans ton navigateur
4. Ajoute la source navigateur dans OBS avec l'adresse de l'overlay
